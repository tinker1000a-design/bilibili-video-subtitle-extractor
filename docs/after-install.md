# 首次部署完成后的收尾

> 这份文件是写给 AI 助手看的。首次在本机部署成功（`.runtime` 刚建好、技能刚装上）时，
> 做完第 1 节，然后把第 2 节的模板**原样放在你回复的最后**。

## 1. 装技能（一条命令，别手工改路径）

```powershell
.\.runtime\Scripts\python.exe scripts\install_skill.py
```

它会读出 `skills/video-digest/SKILL.md`，把里面的 `{REPO}` 换成本机克隆路径，再写进机器上
探测到的技能目录（WorkBuddy / DeepSeek Harness / Claude Code / Codex / `.agents/skills` 中已存在的那些）。`no_target` 时需明确指定 `--target`；`conflict` 时报告冲突路径，不自动覆盖。

输出一行 JSON，重点看两个字段：

| 字段 | 含义 |
|---|---|
| `installed[].path` | 技能写到了哪里，报给用户 |
| `first_time` | `true` 表示这是本机第一次装 —— **只有这时才输出第 2 节的教程** |

`first_time` 为 `false` 说明以前装过、这次只是更新，**不要再贴一遍教程**，一句话说明「技能已更新」即可。

装完这个技能之后，用户在新窗口里发一条视频链接加一句「总结」，就会自动命中，不需要再提任何命令。

## 2. 教程模板（放在回复最末，原样输出）

只替换 `{{仓库路径}}`，其余照抄。不要加标题层级、不要扩写。

```
——
✅ 装好了。以后不用碰 F12，也不用记命令。

怎么用：把链接丢给我，后面随便加一句。
    https://www.bilibili.com/video/BVxxxxxxxx   总结
    https://b23.tv/xxxxxx                       zj
  也认：总结视频 / 总结视频内容 / 这个视频讲什么 / 提炼要点

我会依次做完：取字幕 → 保留原稿 → 简繁统一展示与分段 → 出带时间点的文稿 → 讲清内容。ASR 的术语修订单独保存。

  有字幕       1～2 秒出结果
  登录过期     我会问你要不要扫码，扫完自动接着跑
  真没字幕     我会先说明，再问你要不要花时间做语音转写

文稿在：{{仓库路径}}\outputs\<BV号>_p<分P号>\transcript.md

想换模型、只探不转、重新生成，直接跟我说，不用背参数。
——
```

## 3. 两件容易做错的事

- **不要提前输出教程。** `first_time` 为 `false` 还贴一遍，会让老用户以为重装了。
- **不要跳过安装直接贴教程。** 技能没装成，用户在新窗口发链接是不会自动触发的，教程就成了假的承诺。
  `install_skill.py` 报错时如实说明，不要用「大概装好了」糊过去。

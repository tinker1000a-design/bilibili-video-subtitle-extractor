# 实测范围

日期：2026-10-17。Windows、Python 3.12，依赖见 `scripts/requirements.txt`。

以下为历史手工实测记录，不代表当前修复版已再次完成真人扫码或真实视频 ASR。当前默认需显式同意才转写；自动回归与发布验收见 `docs/releasing.md`。

案例：Bilibili `BV16vdHBPExG`，《Flask作者删光MCP，我劝你别再学》，音轨时长 202.688 秒。

- B站专用 API 返回正确 BV/CID、标题及字幕状态；未登录需要登录才能读字幕轨道。此时仅下载公开音轨，大小 1,665,286 字节，取得音轨约 1.4 秒。没有下载视频帧。
- 通用 yt-dlp 的 `--generic --native-only` 识别到 BiliBili extractor，如实返回 `no_native_captions`。
- 本地 faster-whisper small、CPU int8，全片语音转写完成，约 36.9 秒（不含首次模型下载），得到 61 个 ASR 段落。文字能支持主题理解，但专名、同音词存在识别错误，不作为人工核校字幕。
- 安装后的单命令入口真实运行两次：small 模型约 37.3 秒，65 个分段；turbo 模型约 59.6 秒，100 个分段。两次都完成“URL → 查询字幕 → 仅取音轨 → ASR → TXT/SRT/JSON”。耗时包含模型加载和识别，不含首次模型下载；小额音轨下载另约 1–2 秒。
- 默认采用 turbo；模型缓存已保留。已通读 turbo 转写文本，确认足以梳理视频论点；专名及部分同音词仍需复查，不把低置信度提示为空解释成文字完全准确。
- 合成 SRT、VTT、Bilibili JSON、JSON3、TTML 的文本和时间解析通过，SRT 写出再读取一致。
- 安装后的技能通过 UTF-8 模式的 `quick_validate.py`；脚本实测覆盖 API、通用原生字幕检查、仅音轨获取、本地转写。

用户明确排除了截图识别字幕，技能不包含截图、抽帧和 OCR 路线。

未实测范围：其他站点的联网完整提取、登录字幕、付费和 DRM 视频。通用路线依赖当前 yt-dlp 网站适配。ASR 存在术语、专名、数字及同音词错误，分段时间不是经过人工对齐的逐字时间。

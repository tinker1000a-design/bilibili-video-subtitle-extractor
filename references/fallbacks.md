# 获取失败与转写复查

- 未发现字幕候选且公开音轨可用：先报告原因、耗时与模型下载，经用户明确同意后才转写。凭据问题、下载/解析失败和空字幕先处理对应问题。禁止截图、抽帧或 OCR。
- 当前要求登录：报告当前权限缺口；不将空字幕列表解释成站点完全没有字幕。
- yt-dlp 不支持：检查页面是否提供公开字幕链接或内嵌音视频地址，使用当前可用工具读取。不要用简介、AI 总结替代字幕。
- 原生轨道下载成功但解析为空：检查原始 SRT/VTT/JSON/TTML 格式并补充解析器；保留原件，不能报告已成功提取。
- 网站适配失效：可只更新隔离环境的 yt-dlp，记录版本后重试一次同一 URL。
- 模型下载失败：检查具体下载任务，不反复重建环境；缓存和下载位置在技能目录 `.models`。
- `faster-whisper==1.2.1` 与实测 `av==19.0.1` 出现 `metadata_errors` 参数不兼容，使用已验证的 `av==16.0.1`；不要不加区别地升级全部依赖。
- 专名、数字、英文缩写错误：先回听对应片段，可以用短术语表重试该音频；原始识别与校订文本分别保留。
- 没有可用声音、公开音轨或访问受到 DRM 限制：如实报告阻碍，保留已获得的元数据，不能用截图路线替代。

技术参考：[faster-whisper 官方仓库](https://github.com/SYSTRAN/faster-whisper)。默认 turbo 多语言模型在本地 CPU 上运行，不需要可用的 CUDA 环境。
